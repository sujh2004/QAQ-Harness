# 错误码规范

## 分段规则

错误码为六位数字，格式 AABBBB：前两位标识服务，后四位标识具体错误。

- 10：订单服务 order-service
- 20：优惠券服务 coupon-service
- 30：库存服务 inventory-service
- 40：支付服务 payment-service

## 保留错误段

- 00BBB：通用错误。001 参数非法，002 未登录，003 无权限，004 系统内部错误，005 依赖服务不可用。
- AABB99：该服务未知错误，禁止具体使用。

## 使用要求

跨服务传递错误时保留原始错误码并加本服务前缀，例如优惠券返回 200014，订单侧透传时包装为 102014。错误码一旦发布不可复用、不可变更含义。

## 常见错误码

- 100101：订单不存在
- 101001：创建订单失败
- 102014：优惠券服务不可用（透传自优惠券服务）
- 103001：库存不足
- 103002：库存服务超时
